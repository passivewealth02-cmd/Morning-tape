Complete worked example — the Homeschool Command Center™ (a DUAL-FORMAT product:
18-tab workbook + 12-page printable PDF). These four files are a full, runnable
template. To build a new product, copy the structure and swap the domain content:
the sample-data constants at the top, the per-tab builder functions, the KPIS,
the crest, the content_*() functions, and the PDF pages. The shared helper blocks
at the top of each file are identical across ALL products — do not change them.

Run order:  python3 build_xlsx.py && python3 build_pdf.py && \
            python3 build_marketing.py && python3 build_marketing_detail.py
