# ETSY_LISTING.md template

Fill this structure for every product. Keep it copy-paste ready.

## 1. TITLE (Etsy max 140 chars — give 3 options, count chars)

- **Primary (recommended):** lead with the highest-intent search phrase +
  the differentiator, then stack long-tail feature words and "Excel & Google
  Sheets" (or "Google Sheets + Printable PDF").
- **Alternate A** — a second angle (money/outcome).
- **Alternate B** — a third angle (all-in-one/dashboard).
- Add a short "Title strategy" note.

## 2. TAGS (exactly 13, each ≤20 chars — verify the length of each)

Pair 2–3 high-intent tags with feature/differentiator tags. Add a "Tag notes"
line with swap-in test ideas.

## 3. CATEGORY & ATTRIBUTES

Category: Paper & Party Supplies › Paper › Stationery › Templates (or Planners).
Type: Digital download (instant). File types: XLSX, Google Sheets link, PDF.
Who made it: I did. What is it: a template / finished digital product.

## 4. DESCRIPTION (inside a ``` code block so it's copyable)

```
★ <PRODUCT NAME>™ — <ONE-LINE PROMISE> ★
<2–3 sentence hook: what it replaces, the outcome, "not a X — a complete Y system">

──────────────────────────
<emoji> WHY YOU'LL LOVE IT
──────────────────────────
✔ 8–12 benefit bullets (lead with the dashboard + the health/on-track score)

──────────────────────────
📋 WHAT'S INSIDE — <N> TABS
──────────────────────────
• one line per tab

(dual-format only) 🖨 THE 12 PRINTABLE PAGES — list them

──────────────────────────
📲 HOW IT WORKS   (4 steps)
📦 WHAT YOU RECEIVE   (files)
💻 COMPATIBILITY   (Excel / Google Sheets / print; ✘ not Apple Numbers)
⚡ INSTANT DOWNLOAD   (digital, final sale, 24-hr help)
🎁 PERFECT FOR   (audiences + gift angle)
──────────────────────────
★ Favorite this ♥ and <call to action>.
#hashtags (8)
```

Add a compliance line where relevant: gig products → "Not affiliated with
Lyft/Uber/DoorDash…"; homeschool → "requirements vary by state — not legal
advice"; anything imitating a brand → keep crest/wordmark original, no logos.

## 5. PRICING & RANK BOOSTERS

A 5-row SKU table (Excel-only / Sheets-only / **Bundle** (hero) / Plus add-on /
Pro-or-commercial license). Then 3–4 bullets: seasonality, which 2 photos are the
strongest proof, the two marketing angles to alternate, and the AOV upsells.
